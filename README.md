## 📱 Fitur — Arsitektur Premium

- **Kasir Presisi** — keranjang, diskon, pajak 11% otomatis, total akurat, 3 metode bayar (Cash / QRIS / Transfer)
- **Kurasi Produk** — foto produk, kategori, stok real-time, filter
- **Manajemen Meja** — visual 3 status tenang: Kosong / Terisi / Reservasi
- **Intelijen Laporan** — harian / mingguan / bulanan, grafik navy elegan, export CSV ke Downloads
- **Brankas Data** — Backup 1 ketuk ke Downloads, Restore kapan saja (MediaStore, Android 7–14)
- **Cetak Prestise** — struk thermal 58mm/80mm via Bluetooth ESC/POS, rapi seperti struk hotel
- **100% Offline** — tanpa internet, tanpa iklan, tanpa langganan. Data milik Anda.

## ⚡ Cara Pakai

### Install
1. Unduh APK terbaru di **[Releases](https://github.com/Chukie99/KasirPro/releases)**
2. Buka file di HP → **Install**
3. Buka KasirPro → masukkan Serial Number (8 karakter) → **Buka Akses**

> Aktivasi berbasis Device ID — 1 lisensi untuk 1 perangkat. Hubungi penjual untuk aktivasi.

### Update (tanpa hapus data)
1. Unduh APK versi terbaru dari Releases
2. Ketuk file → pilih **UPDATE** (jangan Uninstall)
3. Selesai — produk, transaksi & laporan tetap utuh

> Tips: sebelum update → **Pengaturan → Backup Database** (1 ketuk, tersimpan di Downloads)
