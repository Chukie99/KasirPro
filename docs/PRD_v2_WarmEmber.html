🏗️ 5 — Arsitektur & Guard Anti-FC

Stack

  • MVVM + Repository + Room + Hilt + Navigation Compose
  • AppDatabase.kasirpro.db + fallbackToDestructiveMigration
  • MainActivity minimal: installSplashScreen() + Hilt prefs + Theme{ NavHost } — jangan logic berat di onCreate
  • Theme.kt: jangan custom Shapes — pakai default M3 Shapes. Cuma ganti colorScheme Warm Ember.

Guard Semua HP (API 27)

  • Vector drawable: semua pathData valid di API 24+, tidak ada gradient di vector
  • Adaptive icon: drawable-v26/ic_launcher.xml + fallback drawable/ic_launcher.xml legacy — keduanya Warm Ember, tidak belang
  • SplashScreen: Brush.verticalGradient(primary→primaryContainer) aman, delay 1.2s via LaunchedEffect
  • ImageHelper: decode + downscale 512px di IO dispatcher, bukan main thread
  • Test matrix: Robolectric @Config(sdk=[24,27,34])
Kenapa dulu FC: WarmShapes pakai RoundedCornerShape(10.dp..32.dp) + legacy icon masih navy → di Semua HP (vector compat) inflate gagal pas MaterialTheme → crash sebelum setContent. Fix v2: hapus custom Shapes, sync semua icon.
